NOW — o que resta agora

Cards por provedor com layout invariante: a janela de 5 horas sempre acima da semanal. Percentual, reset com contagem regressiva, tokens e custo estimado.

BURN — vai durar?

Uso real + projeção pontilhada no ritmo atual, com veredito explícito — "acaba às 16:40". Janela esgotada mostra "nada para queimar", nunca um falso "seguro até o reset".

RHYTHM — quando você queima

Padrão horário local em 24 barras — hoje ou 7 dias — com a hora atual destacada.

MODELS — qual modelo está saudável

Família Claude e modelos OpenAI com probe ao vivo — OK, limitado ou erro — e uso por modelo derivado dos seus próprios transcripts.

Privacidade

Suas credenciais não viram nossos dados.

O NotchAgent não tem backend, não tem telemetria e não tem conta. Tudo lê arquivos locais do seu disco.

  • Keychain do macOS. Credenciais de API nunca saem da sua máquina.
  • Sem backend. Nenhum servidor recebe seu uso.
  • Código aberto. Leia cada linha antes de rodar.
  • Probe opcional. O único pedido de rede é um probe de 1 token pra API da Anthropic — desligável em Ajustes.

O que é medido

Todo número mostra de onde veio.

Uma leitura oficial da API nunca é misturada com uma estimativa.

Fonte Real Estimado
Probe da Anthropicopcional, ~1 token/min — headers anthropic-ratelimit-unified-* via OAuth local do Claude Code % oficial 5h/7d, resets, status allowed/warning/rejected, janela limitante, saúde por modelo —
Transcripts do Claude~/.claude/projects/**/*.jsonl Tokens (input/output/cache), modelo por mensagem, blocos de 5h, ritmo horário Custo (tabela pública em PricingTable.swift)
Rollouts do Codex~/.codex/sessions/** % exato por janela — planos só-semanais como o Spark são detectados — resets, plano, tokens Custo
Gemini CLI~/.gemini/tmp/*/logs.json Prompts, sessões, última atividade Tokens não existem em disco — o app declara isso, nunca inventa.

Token OAuth: CLAUDE_CODE_OAUTH_TOKEN → ~/.claude/.credentials.json → Keychain (consentimento do macOS). Nunca logado; nunca sai da máquina exceto para api.anthropic.com. Desligável em Ajustes.
